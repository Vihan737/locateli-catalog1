# کاتالوگ لوکاتلی + چت مشاور محصولات (نسخه‌ی مستقل و رایگان)

این پوشه یک نسخه‌ی کامل و مستقل از کاتالوگه که:
- روی هر هاستی (Vercel، سرور خودتون، هرجا) بالا میاد
- هیچ نوار "Sign in" یا "Open in app" نداره — تمام‌صفحه‌ست
- چتِ مشاور محصولات براش **برای همه‌ی مشتری‌ها** کار می‌کنه، نه فقط کسایی که حساب Claude دارن
- از **Gemini API گوگل** استفاده می‌کنه که تا امروز بدون کارت بانکی و رایگانه (سقف حدود ۱۵۰۰ درخواست در روز — برای یه فروشگاه کوچیک خیلی زیاده)

## چیدمان پوشه

```
locatelli-chat-backend/
├── public/index.html   ← خود کاتالوگ (فایل نهایی که مشتری می‌بینه)
├── api/chat.js          ← سرور کوچیکی که به هوش مصنوعی وصل می‌شه
├── api/system-prompt.js ← دانش و لحن مشاور (از خود کاتالوگ استخراج شده)
├── vercel.json
├── package.json
└── .env.example
```

## مرحله ۱ — گرفتن کلید رایگان Gemini

۱. برید به آدرس: **aistudio.google.com/apikey**
۲. با حساب گوگلتون وارد بشید (همون جیمیل معمولی، نیازی به چیز خاصی نیست)
۳. روی **Create API key** بزنید
۴. یه پروژه‌ی جدید انتخاب کنه یا خودش می‌سازه — تأیید کنید
۵. کلیدی که نشون داده می‌شه (با `AIza` شروع می‌شه) رو کپی کنید و جایی موقت ذخیره کنید

هیچ‌جای این مسیر کارت بانکی نمی‌خواد. اگه جایی خواست، یعنی رفتید توی مسیر اشتباه (Vertex AI به‌جای AI Studio) — همون aistudio.google.com/apikey رو دنبال کنید.

## مرحله ۲ — انتشار روی Vercel (رایگان و ساده‌ترین راه)

۱. یه حساب رایگان توی [vercel.com](https://vercel.com) بسازید (می‌تونید با گیت‌هاب وارد بشید).
۲. این پوشه رو توی یه ریپازیتوری گیت‌هاب آپلود کنید، یا مستقیم با Vercel CLI:
   ```
   npm install -g vercel
   cd locatelli-chat-backend
   vercel
   ```
۳. توی داشبورد Vercel، برید توی تنظیمات پروژه → **Environment Variables** و این‌ها رو اضافه کنید:
   - `GEMINI_API_KEY` = کلیدی که مرحله‌ی قبل گرفتید
   - `ALLOWED_ORIGIN` = دامنه‌ی نهایی‌تون — یا خالی بذارید تا محدود نباشه
۴. یه بار دیگه دیپلوی کنید (`vercel --prod`) تا این تنظیمات اعمال بشه.
۵. آدرسی که Vercel بهتون می‌ده (چیزی شبیه `locatelli-catalog.vercel.app`) رو باز کنید — همین آدرس **رایگان** برای همیشه در دسترسه، نیازی به خرید دامنه نیست. کاتالوگ باید تمام‌صفحه و بدون هیچ نواری باز بشه.

## مرحله ۳ — دامنه‌ی شخصی (کاملاً اختیاری)

اگه بعداً خواستید لینک قشنگ‌تری داشته باشید (مثل `catalog.vismanpen.com`)، توی داشبورد Vercel → **Domains** اضافه‌ش کنید. ولی این هیچ ربطی به کارکردن سایت نداره — همون لینک رایگان vercel.app هم کامل کار می‌کنه.

## تست چت

بعد از دیپلوی، از صفحه‌ی «تماس با ما» بزنید روی «چت با مشاور محصولات» و یه سؤال بپرسید. برای هر بازدیدکننده‌ای کار می‌کنه، بدون Sign in.

## هزینه‌ها

- **Vercel**: پلن رایگانش برای این حجم ترافیک کافیه.
- **Gemini API**: رایگان، بدون کارت بانکی، تا سقف روزانه‌ای که برای یه فروشگاه کوچیک به‌ندرت بهش می‌رسید.

اگه یه روز فروشتون زیاد شد و به سقف رایگان رسیدید، همون‌جا می‌تونید کارت بانکی اضافه کنید تا سقف برداشته بشه — یا به مدل‌های ارزون Anthropic (که قبلاً هم آماده کرده بودم) سوییچ کنید.

## تغییر دادن دانش یا لحن مشاور

فایل `api/system-prompt.js` همون متنیه که به مشاور می‌گه چطور حرف بزنه و چه چیزی درباره‌ی محصولات بدونه. برای تغییرش:
- اگه محصول جدید اضافه کردید یا مشخصات عوض شد، بگید که در Claude این فایل رو دوباره از روی کاتالوگ به‌روز کنه.
- اگه فقط لحن رو می‌خواید عوض کنید، مستقیم متن داخل این فایل رو ویرایش کنید و دوباره دیپلوی کنید.

## نگه‌داشتن این نسخه هم‌گام با آرتیفکت claude.ai

این یک فایل جدا از آرتیفکتیه که روی claude.ai منتشر شده. هر تغییری (محصول جدید، عکس جدید، اصلاح متن) باید توی هر دو جا اعمال بشه — یا از Claude بخواید هر دو رو با هم به‌روز کنه.
