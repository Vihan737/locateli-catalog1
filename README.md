# کاتالوگ لوکاتلی روی Vercel (نسخه‌ی v136)

کاتالوگ کامل + چت «مشاور محصولات» که برای همه‌ی مشتری‌ها کار می‌کند (بدون نیاز به حساب Claude).

```
public/            ← خود کاتالوگ (index.html، عکس‌ها، آیکون‌ها، فیلم معرفی)
api/chat.js        ← تنها فایل سرور چت (دانش و لحن مشاور داخل خودش است)
scripts/           ← آدرس سایت را هنگام دیپلوی در پیش‌نمایش لینک می‌نویسد
vercel.json        ← تنظیمات (زمان مجاز چت ۶۰ ثانیه، کش عکس‌ها)
package.json
```

## ۱) کلید رایگان هوش مصنوعی
- **Gemini (پیشنهادی)**: `aistudio.google.com/apikey` → Create API key → کلید را کپی کنید.
- **Groq (پشتیبان)**: `console.groq.com/keys` → Create API Key.
- هر دو را هم می‌توانید بگذارید؛ اگر اولی جواب نداد، سرور خودکار سراغ دومی می‌رود.

## ۲) آپلود روی GitHub
۱. فایل ZIP را باز (Extract) کنید.
۲. در ریپازیتوری GitHub: **Add file → Upload files**.
۳. **محتوای داخل** پوشه‌ی باز‌شده را بکشید و رها کنید: پوشه‌های `public`، `api`، `scripts` و فایل‌های `vercel.json`، `package.json`، `README.md`
   (خود پوشه‌ی بیرونی را نکشید؛ این‌ها باید مستقیم در ریشه‌ی ریپازیتوری باشند).
۴. صبر کنید شمارنده‌ی آپلود تمام شود، بعد **Commit changes**.
۵. در صفحه‌ی ریپازیتوری مطمئن شوید پوشه‌ی `api` و داخلش `chat.js` دیده می‌شود.

## ۳) Vercel
۱. اگر پروژه از قبل به این ریپازیتوری وصل است، بعد از Commit خودش دیپلوی می‌کند.
   اگر نه: `vercel.com/new` → Import همین ریپازیتوری → Framework: **Other** → Deploy.
۲. **Settings → Environment Variables**: `GEMINI_API_KEY` = کلید (و در صورت داشتن، `GROQ_API_KEY`).
۳. **Deployments** → سه‌نقطه‌ی آخرین دیپلوی → **Redeploy** (بعد از هر تغییر کلید لازم است).

## ۴) بررسی
| آدرس | باید ببینید |
|---|---|
| `https://آدرس-سایت/api/chat` | `"ok": true` و نام کلیدهایی که ست شده |
| `https://آدرس-سایت/api/chat?diag=1` | `"working": true` |
| `https://آدرس-سایت/api/chat?diag=full` | یک پاسخ واقعی مشاور به فارسی |
| `https://آدرس-سایت/` | کاتالوگ؛ از صفحه‌ی «تماس با ما» → «چت با مشاور محصولات» یک سؤال بپرسید |

## عیب‌یابی
- `/api/chat` خطای **404** می‌دهد → پوشه‌ی `api` آپلود نشده (مرحله‌ی ۲ را تکرار کنید).
- `"keysSet": []` یا `"present": false` → کلید در Environment Variables نیست یا بعدش Redeploy نشده.
- `API key not valid` → کلید ناقص کپی شده؛ دوباره کپی کنید (بدون فاصله).
- `User location is not supported` → این کلید Gemini در دسترس نیست؛ `GROQ_API_KEY` هم اضافه کنید.
- `quota` / `429` → سهمیه‌ی رایگان آن مدل تمام شده؛ سرور خودکار مدل بعدی را امتحان می‌کند. داشتن کلید دوم (Groq) کمک می‌کند.
- برای دیدن متن دقیق خطا داخل خود چت: به آخر آدرس کاتالوگ `?debug=1` اضافه کنید.

## نکته‌ها
- پیش‌نمایش لینک در واتساپ/تلگرام (عکس و عنوان) خودکار با آدرس سایت تنظیم می‌شود.
- دانش مشاور داخل `api/chat.js` است و با کاتالوگ هماهنگ ساخته شده؛ برای تغییر محصولات، از Claude بخواهید هر دو را با هم به‌روز کند.
